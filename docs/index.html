Nio Orca — Sovereign vMicroLM Pod Fleet

Sub-600MB RAM specialist coding fleets (0.5B / 1.5B) that run on small devices, self-verify every code block by default, and beat Qwen2.5-Coder-7B-Instruct INT4.

Nio Orca replaces monolithic 7B–14B models with a 13-pod specialist fleet (1× Lead + 6× Action Pods + 6× Reasoner Pods) routed dynamically via pod_manifest.json and executed in native Rust by nio-xs.

How We Benchmark (Methodology)

  • Datasets: Full openai/openai_humaneval (164 tasks) and google-research-datasets/mbpp (sanitized, 100 tasks) in isolated Python subprocesses with a 5s timeout.
  • Baselines: 3B & 7B INT4 were evaluated in the same multi-round harness; *Qwen2.5-Coder-14B-Instruct (FP16) is the published single-shot Pass@1 baseline from arXiv:2409.12186.
  • Orca Protocol: Orca Nano (32-round 0.5B FP16 hybrid), Orca Mini (16-round 1.5B INT4), and Orca Omni (2 fast 0.5B rounds + 16 1.5B escalation/repair rounds) use the same error-guided + fresh-restart --verify loop built into nioxs. Host VmHWM and CPU speed were measured on i7-10610U with Q4_K_M.gguf.

3. Quickstart

1. Install the Sovereign Engine (nioxs)

curl -fsSL https://raw.githubusercontent.com/nio-labs/nio-xs/main/install.sh | bash

For native Windows (PowerShell):

irm https://raw.githubusercontent.com/nio-labs/nio-xs/main/install.ps1 | iex

2. Pull Weights & Run Locally (--verify is ON by default)

# Pull verified Q4_K_M pods from nio-labs/nio-xs-models (v0.6.0)
nioxs pull orca-nano   # 13 pods (~4.9 GB)
nioxs pull orca-mini   # 13 pods (~12.2 GB)
nioxs pull orca-omni   # 26 pods (~17.1 GB)

# Optional Wave 1 Domain Bundles (v0.6.1, ~760 MB/bundle)
nioxs pull health-wellness
nioxs pull everyday-home

# Run with automatic pod routing & bounded --verify self-repair
nioxs orca-nano "Write a Python function fib(n) with assert fib(6) == 8"
nioxs orca-omni "Implement a lock-free ring buffer in Python with tests"
nioxs orca-omni --think "Implement topological_sort(n, edges) with cycle detection"

4. The v-µLM Pods Architecture

  • 1× Lead Pod: Fast default router & general coding responder.
  • 6× Action-First Pods (pod_0…pod_5): Direct code synthesis matched dynamically by salient domain terms in pod_manifest.json.
  • 6× Dedicated Reasoner Pods (reasoner, architect, algo_reasoner, repair_reasoner, test_reasoner, security_reasoner): Bounded <think> invariant analysis & error-guided repair when --verify catches a failure.

5. Tier Ladder & Roadmap

  • Orca Nano (0.5B × 13, ~4.9 GB): Live in v0.6.0 — ~582 MB RAM, ~20 w/s CPU, 85.37% HumanEval.
  • Orca Mini (1.5B × 13, ~12.2 GB): Live in v0.6.0 — ~1,839 MB RAM, 8–10 w/s CPU, 86.59% HumanEval.
  • Orca Omni (0.5B + 1.5B, ~17.1 GB): Live in v0.6.0 — 92.07% HumanEval / 89.0% MBPP.
  • Orca Max (0.5B Fast + 12× 3B, ~22.0 GB) & Orca Ultra (0.5B Fast + 12× 7B, ~50.8 GB): Planned workstation & high-VRAM hybrid tiers for multi-file project boilerplate (--out <dir>) and project-level --verify.
  • Orca Pods: Installable domain bundles (Wave 1: health-wellness, everyday-home; Wave 2+: math, history, general-knowledge, microservices) shared across every tier.

Edge & Hardware Support

  • Raspberry Pi 4 / Pi 5 (4GB / 8GB+) & ARM64 SBCs: Run Orca Nano (~582 MB RAM, 380 MB/pod) or offline Orca Pods on a $35–$80 SBC (Raspberry Pi, Orange Pi, Jetson Orin Nano) with zero cloud fees.
  • CPU-Only Laptops & Desktops (Linux / macOS / Windows): Run Orca Nano, Orca Mini (~1.8 GB RAM), and Orca Omni natively on CPU with no GPU required.
